# **RFEA Analyzer – User Manual**

## 1. Introduction

**RFEA Analyzer** is a desktop application designed for the analysis of **Ion Energy Distribution Functions (IEDF)** obtained from **Retarding Field Energy Analyzer (RFEA)** measurements in plasma experiments.

The software allows users to:

- Load RFEA CSV data files
- Compute averaged I–V curves
- Apply configurable smoothing algorithms
- Extract the IEDF
- Estimate plasma parameters (ion flux, density, average energy)
- Compute the **ion transit time to RF period ratio (τᵢ / τ_rf)**
- Visualize and export results

The application is intended for **researchers, engineers, and students** working with low-temperature plasmas.

## 4. Loading Data

### 4.1 Opening a CSV file
the csv file must have been exported from Semion software using semicolon or coma

1. Click **“Open CSV…”**
2. Select an RFEA CSV file using the file explorer
3. The file path will appear in the interface
4. The analysis runs automatically

### 4.2 CSV File Structure

The CSV file must contain:

- Electrode voltage (header line)
- Ion flux reference value
- Multiple I–V traces separated by blank or NaN rows

(Compatible with the MATLAB RFEA acquisition format.)

## 5. Analysis Parameters

### 5.1 Gas and grids parameter
- **Grids transmission** is by default 53.9% for low density it is 70%
- **Number of holes** is 37 by default
- **Radius of holes** is 0.4mm or 0.0004m by default
- **Gas for cross-sections**: so far only Ar and He are available. Ar Impedans is 8.8e-19m2, Ar kinetic is 5.1e-19m2 and He impedans is 2.9e-19m2

### 5.2 Pressure

- **Units:** same as acquisition (typically Pa or mTorr)
- Used for ion flux correction

### 5.3 Smoothing of dI/dE

- **dI/dE smoothing (eV)**, default **1 eV**
- Width of the moving average applied to the IEDF (the derivative of the I–V curve)
- Higher values → smoother IEDF, less noise, but broader peaks
- The width is in eV, so the same value works for any voltage step of the sweep

Before any method, the averaged I–V curve gets a light 1 eV noise filter. All
smoothing windows are rounded to an odd number of points, so they never shift
the curve, and each slope is placed at the middle of its voltage step.

### 5.4 I–V Smoothing Method

Choose one of the following:

### Recursive (recommended)

Peak-preserving smoothing:

1. Finds every significant peak of the IEDF (at least 20 % of the strongest).
2. Leaves the I–V curve **unsmoothed within ± Peak protection (eV)** of each
   peak (default ±10 eV), so the peak shape is kept. These zones are shaded
   on the plot.
3. Outside, smooths with a moving average that widens with the distance from
   the zone (up to ±5 eV) but never reaches into it, so there are no kinks at
   the zone edges.
4. Detects the peaks again on the result and repeats until they stop moving.

E<sub>peak</sub> is read from a parabola fitted to the top of the highest peak,
not snapped to the nearest data point.

On synthetic test data with a known IEDF (`web/tests/benchmark.cjs`) it is the
most accurate method: about 0.1 eV error on E<sub>peak</sub> and E<sub>avg</sub>,
for sparse (0.5 V) and dense sweeps and for double-peaked IEDFs.

*Changed in the web version:* the original algorithm counted its windows in
data points (100 and 200), so it failed on sparse sweeps, and it crashed when a
data point fell exactly on the edge of the protected zone. The Python desktop
app (tag `python-final`) still uses the original algorithm.

### Moving Average (Mavg)

- Simple moving average
- Window in data points (default 5; use an odd number)

### Savitzky–Golay (SG)

- Polynomial smoothing
- Parameters:
    - Polynomial order
    - Window length in data points (odd number)

## 6. Plasma & Sheath Parameters (τ Ratio)

These parameters are used to compute the **ion transit time to RF period ratio**:

### 6.1 Vp – Plasma Potential

- **Units:** Volts (V)
- Typical range: 10–50 V

### 6.2 Mi – Ion Mass

- **Units:** atomic mass unit (u)
- Examples:
    - Argon: 40
    - Helium: 4
    - Oxygen: 16

### 6.3 f_rf – RF Frequency

- **Units:** Hz
- Default: 13.56 MHz

### 6.4 Te – Electron Temperature

- **Units:** eV
- Default: 3 eV

### 6.5 α – Sheath Expansion Factor

- Dimensionless
- Default: 3

---

## 7. Output Quantities

The application computes and displays:

- **Eavg** – Average ion energy (eV)
- **Flux** – Ion flux (m⁻²·s⁻¹)
- **ni** – Ion density (m⁻³)
- **Epeak** – Energy at IEDF maximum (eV)
- **τᵢ / τ_rf** – Ion transit time to RF period ratio
- **Electrode voltage**
- **Imported ion flux reference**

---

## 8. Plot Description

### 8.1 Left Axis (Current)

- **Black curve:** Averaged I–V curve (`I`)
- **Green curve:** Smoothed I–V curve (`Ismooth`)

### 8.2 Right Axis (IEDF)

- **Red curve:** Ion Energy Distribution Function (dI/dE)

### 8.3 Interactivity

The plot supports:

- Zoom
- Pan
- Reset view
- Save image
- Cursor hover readout (energy and values)

## 9. Exporting Results

### 9.1 Export Data (CSV)

Click **“Export data (CSV)…”** to save:

- Vavg
- Iavg
- Ismooth
- E
- IEDF (dI/dE)

All arrays are aligned and padded if needed.

### 9.2 Export Plot

Click **“Export plot (PNG/SVG)…”** to save:

- High-resolution PNG (publication ready)
- SVG vector format (recommended for figures)

## 11. Typical Workflow

1. Open CSV file
2. Verify I–V and IEDF shapes
3. Adjust smoothing parameters
4. Set plasma/sheath parameters
5. Check τᵢ / τ_rf value
6. Export data and figures

---

## 12. Notes & Recommendations

- Start with **Recursive smoothing**
- Avoid excessive smoothing of dI/dE
- Ensure Vp and Mi values match experimental conditions
- Use SVG export for publications
